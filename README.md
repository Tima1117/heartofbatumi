# Pizza Room Batumi — concept redesign

Responsive, multilingual demo website for Pizza Room Batumi. Built with Next.js, TypeScript, CSS and Framer Motion.

## Features

- 15 independently clickable pizza cards with ingredients and prices from the restaurant's published menu image.
- English, Russian and Georgian interface.
- Rotating, scroll-responsive hero pizza; reduced-motion support and a lighter mobile layout.
- Restaurant phone, directions and Wolt ordering links.
- Two wayfinding photos from the restaurant's website and an embedded OpenStreetMap map.
- Original Pizza Room logo used for the website icon.

## Run locally

```bash
npm ci
npm run dev
```

## Content notes

This is an unsolicited **concept**, not an official Pizza Room website. Verify all menu items, ingredients, hours and prices with the restaurant before production use. The displayed prices come from [Pizza Room's published menu](https://pizzaroom.ge/wp-content/uploads/2026/08/A3-03-03-2026-price-Pizza-Room_Batumi.jpg); Wolt delivery prices may differ. Most product photos were provided by Pizza Room via its [Wolt listing](https://wolt.com/en/geo/batumi/restaurant/pizza-room-batumi). The hero pizza and two menu illustrations (Mushrooms & ham, Vegetarian) are generated visuals and should be replaced with approved restaurant photography before official launch.

The wayfinding photos come from [Pizza Room's website](https://pizzaroom.ge/). The map uses OpenStreetMap with the location coordinates from the restaurant's published map. The photos show older signs, including an old price, so they should be refreshed before an official launch.
